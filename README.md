# 🧮 C Calculator

A simple **calculator program written in C** that performs basic arithmetic operations: addition, subtraction, multiplication, and division.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Takes two integer values as input
* ⌨️ Takes the operation from the user through the terminal

## 🛠️ Requirements

* [Visual Studio Code](https://code.visualstudio.com/)
* C compiler (such as GCC)
* VS Code C/C++ extension

## 🚀 How to Run

### 1. Clone the Repository

Open your VS Code terminal and run:

```bash
git clone YOUR_REPOSITORY_LINK
```

Then open the project folder in VS Code.

### 2. Open the Terminal

In VS Code, go to:

**Terminal → New Terminal**

### 3. Compile the Program

If your file is named `calculator.c`, run:

```bash
gcc calculator.c -o calculator
```

### 4. Run the Calculator

On Windows:

```bash
.\calculator
```

On Linux/macOS:

```bash
./calculator
```

The calculator will now run **directly in your VS Code terminal**.
